# Иконки интерфейса

`icon-sel-*.svg` — иконки шагов конфигуратора подбора (`/podbor` и секция на главной).
Взяты из [Phosphor Icons](https://github.com/phosphor-icons/core), начертание Regular,
лицензия MIT: `car`, `jeep`, `van`, `seat`, `steering-wheel`, `gas-pump`, `mountains`.

При переносе снят комментарий-заголовок и `currentColor` заменён на `#000` — иконки
подключаются через CSS-маску, где `currentColor` не имеет контекста, а цвет задаётся
`background-color` элемента. В конфигураторе он всегда акцентный (`--color-3`).

Иконки сезонов — родные для сайта `icon-season-*.svg`, их не заменять: они же используются
в фильтре каталога.

`icon-wheel-color-2.svg` и `icon-chevron-down-color-2.svg` — собственные, для шапки:
колесо у ссылки «Где купить» и стрелка у пункта с выпадающей панелью. Обе подключены
маской, поэтому нарисованы чёрным.

MIT требует сохранения уведомления об авторстве — эта страница им и является.
