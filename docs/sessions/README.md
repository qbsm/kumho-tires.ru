# sessions

Логи сессий работы с этим deployment'ом — фиксы вёрстки/контента, миграции, рефакторинги.

## Naming convention

`YYYY-MM-DD-<topic-kebab>.md`

Без префикса `session-`. Topic — kebab-case.

## Что писать сюда

- Фикс конкретной страницы / секции этого deployment'а
- Миграция контента (JSON, медиа)
- Локальный refactor шаблонов / стилей
- Содержательная сессия с claude по локальной задаче

## Что НЕ писать сюда

- Создание/изменение ядра платформы → `ismart-platform/docs/sessions/`
- Идея/паттерн для платформы → `../proposals/` (deployment proposal)
- Архитектурное решение → ADR в baseline (только baseline пишет ADR)

## Стиль

Линейный нарратив без P1.1/P2.x. «Проблема → Решение → План» в 3 абзацах для главных моментов. Что создано / обновлено — список.
