# Иконки интерфейса

`icon-sel-*.svg` — иконки шагов конфигуратора подбора (`/podbor` и секция на главной).
Взяты из [Tabler Icons](https://github.com/tabler/tabler-icons), лицензия MIT:
`car`, `car-suv`, `truck`, `armchair`, `steering-wheel`, `gas-station`, `mountain`.

При переносе снят комментарий-заголовок и `stroke="currentColor"` заменён на `#000` —
иконки подключаются через CSS-маску, где `currentColor` не имеет контекста и цвет
задаётся `background-color` элемента.

Штрих 2 на сетке 24 совпадает с сезонными иконками `icon-season-*.svg`, поэтому наборы
читаются как один. Сезонные иконки — родные для сайта, их не заменять.

MIT требует сохранения уведомления об авторстве — эта страница им и является.
